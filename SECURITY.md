# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you find a security vulnerability, please report it by clicking on "Report a vulnerability" under the "Security" tab or by using [this link](https://github.com/iqnite/yt-dlp-ui/security/advisories/new). We will try to fix the issue and release a patch as fast as possible.
